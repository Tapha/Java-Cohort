# DE – Java FSE AWS: Required Software & Tools

For this track, learners should install or have access to the following software before the programme begins.

---

## 1. Core Development Environment

### Required

* Java JDK 18 or higher
* IntelliJ IDEA Community Edition
* Maven
* Gradle
* Git CLI
* GitHub account
* GitHub Desktop or Sourcetree
* VS Code
* Terminal access:

  * macOS/Linux Terminal
  * Windows Terminal or PowerShell
* WSL 2 for Windows users
* SDKMAN or equivalent Java version manager
* ZIP/unzip utility

### Recommended / Optional

* Lombok plugin
* SpotBugs plugin
* Checkstyle plugin
* IntelliJ Test Runner

---

## 2. Testing & Code Quality

### Required

* JUnit 5
* Mockito
* JaCoCo
* SonarLint
* Maven/Gradle test dependencies

### Recommended / Optional

* SonarQube
* Checkstyle
* SpotBugs

---

## 3. Backend Development

### Required

* Spring Boot
* Spring Initializr access
* Postman, Insomnia, or Bruno
* JSON Viewer / Formatter
* Swagger / OpenAPI UI
* Maven or Gradle

### Recommended / Optional

* MapStruct
* Spring Boot DevTools

---

## 4. Database & Data Tools

### Required

* PostgreSQL Server
* pgAdmin 4
* DBeaver
* psql CLI
* SQL Shell
* Flyway or Liquibase

### AWS Database Access

* AWS RDS Console
* Aurora access where required

---

## 5. Frontend / Web Development

### Required

* VS Code
* Node.js LTS
* NPM
* Browser DevTools
* Live Server extension
* ESLint
* Prettier

### Recommended / Optional

* Jest
* Vite

---

## 6. AWS Core Services

### Required

* AWS Console access
* AWS CLI
* AWS IAM access
* VPC Dashboard access
* S3 Console access
* CloudWatch Logs & Metrics
* AWS Educate or AWS Classroom access

### Recommended / Optional

* AWS CloudFormation
* AWS Toolkit for IntelliJ or VS Code

---

## 7. Serverless & Integration

### Required

* AWS Lambda Console
* API Gateway Console
* S3 Event Triggers
* EventBridge
* AWS SAM CLI
* CloudWatch Logs
* AWS X-Ray

### Recommended / Optional

* Serverless Framework

---

## 8. CI/CD

### Required

* Jenkins LTS
* Jenkins Pipeline Plugin
* Git Plugin
* JUnit Plugin
* JaCoCo Plugin
* Credentials Binding Plugin
* Docker

### Recommended / Optional

* Blue Ocean
* SonarQube
* Nexus Repository
* JFrog Artifactory

---

## 9. Containers & Orchestration

### Required

* Docker Desktop
* Docker Hub account or AWS ECR access
* kubectl CLI
* Minikube
* Helm
* YAML support in IDE/editor

### Recommended / Optional

* K9s
* Lens
* YAML Lint

---

## 10. API, Security & Environment Tools

### Required

* OpenSSL
* SSH client
* Environment variable support:

  * `.env` files
  * terminal-based environment variables
* Password manager for storing credentials safely
* Browser with modern developer tools:

  * Chrome, Edge, or Firefox

### Recommended / Optional

* jq for command-line JSON parsing
* curl
* HTTPie

---

## 11. Collaboration & Documentation

### Required

* GitHub account
* Access to cohort GitHub repositories
* Markdown editor or VS Code Markdown preview
* Google Drive / Microsoft OneDrive access if used by the cohort
* Microsoft Teams, Slack, or Discord depending on cohort setup

### Recommended / Optional

* Draw.io / diagrams.net
* Excalidraw
* Notion or OneNote

---

## 12. Minimum Machine Requirements

Learners should ideally have:

* 8GB RAM minimum
* 16GB RAM recommended
* 4-core CPU recommended
* At least 30GB free disk space
* Stable internet connection
* Admin rights on their machine
* Ability to install development software

---

## 13. Windows-Specific Requirements

Windows users should also install:

* Windows Terminal
* WSL 2
* Ubuntu for WSL
* Docker Desktop with WSL 2 backend enabled
* Git Bash

---

## 14. macOS-Specific Requirements

macOS users should also install:

* Homebrew
* Xcode Command Line Tools
* iTerm2 optional

---

## 15. Linux-Specific Requirements

Linux users should ensure they have:

* build-essential or equivalent package
* curl
* wget
* unzip
* Git
* Docker Engine or Docker Desktop
* Java version manager such as SDKMAN

---

# Installation Priority

Learners should prioritise installation in this order:

1. Java JDK
2. IntelliJ IDEA
3. Git
4. Maven / Gradle
5. VS Code
6. PostgreSQL + DBeaver / pgAdmin
7. Postman / Insomnia / Bruno
8. Node.js + NPM
9. Docker Desktop
10. AWS CLI
11. Jenkins
12. kubectl + Minikube + Helm

---

# Final Note

Some tools may only be required later in the programme. However, learners should install the core development tools before the first technical session so they can follow along without setup delays.
