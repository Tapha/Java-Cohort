* Start with High Level Spec 


* High Level Spec:  Document that outlines what you want to accomplish using various definitions
* PRD (Products Requirements Document): what the project should look like without constraint
* Constrained PRD : PRD constrained to the technical, language, database, hosting, etc choices
* Roadmap : Broad set of steps to take to accomplish PRD goal. subdivide the steps into concrete tasks later. Long jumps of project
* Agentic Tasks: Small enough for individual agents to accomplish within context window. Turn the long jumps into actionable steps for agents. Each token refers to a character, context window has set number of tokens

* Agents are like representations of human beings, break down steps to be understandable to them.

* Can get idea ingredients to construct the high level spec with ai, then deconstuct high level spec to make the others
